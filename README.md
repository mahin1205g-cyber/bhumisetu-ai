# LandGuard AI — Unified Digital Land Security Platform
### ডিজিটাল ভূমি নিরাপত্তা প্ল্যাটফর্ম (দলিল যাচাই, স্মার্ট ই-নামজারি ও প্রাক-ক্রয় ডিউ ডিলিজেন্স)
**LandTech Innovation Hackathon 2026 | Problem Statements P2 + P4 + P5**

---

## 🌟 ওভারভিউ (Project Overview)

**LandGuard AI** হলো বাংলাদেশের ডিজিটাল ভূমি সেবা ইকোসিস্টেমের জন্য প্রস্তুতকৃত একটি সমন্বিত, বিশ্বস্ত ও কৃত্রিম বুদ্ধিমত্তা-চালিত ওয়েব অ্যাপ্লিকেশন। প্ল্যাটফর্মটি হ্যাকাথনের তিনটি প্রধান জাতীয় সমস্যাকে একটি একক সরকারি পোর্টাল ইন্টারফেসে একীভূত করেছে:

1. **P2: ডিজিটাল দলিল ও মালিকানা যাচাই (Deed & Ownership Verification):** দলিল নম্বর, বছর, দাগ, খতিয়ান ও মৌজার তথ্যের সাথে সাব-রেজিস্ট্রি বালাম রেকর্ডের ক্রস-চেক, এআই টেক্সট এক্সট্রাকশন (OCR), গরমিল শনাক্তকরণ এবং ডিজিটাল ভেরিফাইড কিউআর সনদ।
2. **P4: স্মার্ট ই-নামজারি ওয়ার্কফ্লো (Smart E-Namjari Workflow):** ৪-ধাপের নির্দেশিত নামজারি ফরম, খসড়া সংরক্ষণ, অনন্য ট্র্যাকিং নম্বর (`MUT-2026-DHK-XXXX`), রিয়েলটাইম টাইমলাইন ট্র্যাকার এবং সহকারী কমিশনার (ভূমি) / এসি ল্যান্ডের অনুমোদন ও পর্যালোচনা ড্যাশবোর্ড।
3. **P5: জমি কেনার আগে প্রাক-ক্রয় নাগরিক যাচাই (Citizen Due Diligence):** বায়না বা ক্রয়ের চুক্তির পূর্বে প্লটের স্বত্ব ধারাবাহিকতা, একাধিকবার বিক্রি, ৩০ দিনের মধ্যে অস্বাভাবিক দ্রুত হস্তান্তর, অধিগ্রহণ নোটিশ বা দেওয়ানি বিরোধ যাচাই করে ০-১০০ ঝুঁকি স্কোর এবং ৫টি জরুরি করণীয়সহ ডিউ ডিলিজেন্স রিপোর্ট।

## 🇧🇩 ভাষা ও থিম সমর্থন (Language & Dark Mode)
- **ডিফল্ট ভাষা (Default Language):** বাংলা (`bn`), বাস্তবসম্মত বাংলাদেশ ভূমি পরিভাষা (মৌজা, খতিয়ান, দাগ, জে.এল, বালাম, নামজারি, ডিসিআর, দাখিলা)।
- **দ্বিতীয় ভাষা (Secondary Language):** ইংরেজি (`en`) — হেডারে থাকা গ্লোব আইকন দিয়ে তাৎক্ষণিক পরিবর্তনযোগ্য।
- **ডার্ক মোড (Dark Mode):** সিস্টেম ও ব্যবহারকারীর পছন্দের সাথে সামঞ্জস্যপূর্ণ পূর্ণাঙ্গ ডার্ক/লাইট মোড সমর্থন (`🌙 / ☀️` টগল)।
- **কালার স্কিম:** বাংলাদেশ সরকারের ডিপ গ্রিন (`#0B462D`), স্বর্ণালী অ্যাকসেন্ট (`#C59B27`) এবং পরিচ্ছন্ন কার্ড লেআউট।

## 🚀 দ্রুত চালানোর নির্দেশনা (Quick Start Guide)

### ১. ডিপেন্ডেন্সি ইনস্টলেশন
```bash
# পাইথন লাইব্রেরি ইনস্টল করুন
pip install -r requirements.txt

# ফ্রন্টএন্ড প্যাকেজ ইনস্টল করুন
cd frontend
npm install
npm run build
cd ..
```

### ২. ব্যাকএন্ড ও সমন্বিত অ্যাপ্লিকেশন চালু করুন
```bash
# ব্যাকএন্ড ফোল্ডার থেকে চালান (এটি বিল্ট রিঅ্যাক্ট ফ্রন্টএন্ডও সরাসরি পরিবেশন করে)
cd backend
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```
👉 ব্রাউজারে খুলুন: **`http://127.0.0.1:8000`**

### ৩. ফ্রন্টএন্ড ডেভ মোডে চালাতে চাইলে (Optional Vite Hot Reloading)
```bash
cd frontend
npm run dev
```
👉 ব্রাউজারে খুলুন: **`http://localhost:5173`** (স্বয়ংক্রিয়ভাবে ব্যাকএন্ড API প্রক্সি করে)

### ৪. স্বয়ংক্রিয় টেস্ট রান করুন
```bash
pytest tests
```
*(সবগুলো টেস্ট স্বয়ংক্রিয়ভাবে সফলভাবে পাস করবে)*

## 🏆 ৫ মিনিটের হ্যাকাথন ডেমো উপস্থাপনা নির্দেশিকা (5-Minute Hackathon Demo)

1. **মিনিট ১: ল্যান্ডিং ও ওভারভিউ**
   - `http://127.0.0.1:8000` এ যান।
   - জাতীয় পরিচয়, ৩টি সমস্যা সমাধান (P2, P4, P5), ডার্ক মোড এবং বাংলা/ইংরেজি ভাষা পরিবর্তন প্রদর্শন করুন।
2. **মিনিট ২: P2 — ডিজিটাল দলিল যাচাই (Deed Verification)**
   - মেনু থেকে **"দলিল ও মালিকানা যাচাই (P2)"**-এ ক্লিক করুন।
   - **"নমুনা ১: শতভাগ মিল"** ক্লিক করে যাচাই বাটনে চাপুন। শতভাগ তথ্যের মিল, বালাম তুলনা এবং সার্ভার-ভ্যালিডেটেড কিউআর কোডসহ সার্টিফিকেট দেখুন।
   - এরপর **"নমুনা ২: নাম গরমিল"** ক্লিক করে যাচাই করুন; লাল সতর্কতাসহ বিক্রেতার নামের গরমিল শনাক্তকরণ প্রদর্শন করুন।
3. **মিনিট ৩: P4 — স্মার্ট ই-নামজারি (E-Namjari Workflow)**
   - **"স্মার্ট ই-নামজারি (P4)"** মেনুতে যান।
   - **"ডেমো তথ্য লোড"** বাটনে চাপুন এবং ৪-ধাপের নির্দেশিত উইজার্ড ঘুরে **"চূড়ান্ত আবেদন দাখিল করুন"** চাপুন।
   - নতুন ট্র্যাকিং নম্বর (যেমন: `MUT-2026-DHK-XXXX`) এবং ভিজ্যুয়াল প্রগ্রেস টাইমলাইন প্রদর্শন করুন।
4. **মিনিট ৪: কর্মকর্তা রিভিউ ও মঞ্জুরি (Officer Review Workflow)**
   - উপরের ডেমো বার থেকে **"২. সহকারী কমিশনার (ভূমি)"** ক্লিক করুন।
   - **"কর্মকর্তা রিভিউ ড্যাশবোর্ড"**-এ দাখিলকৃত আবেদনগুলোর তালিকা ও নথি পর্যালোচনা করুন।
   - **"অনুমোদন করুন"** বা **"অতিরিক্ত তথ্য তলব"** বাটনে ক্লিক করে মন্তব্যসহ সরকারি আদেশ জারি করুন।
5. **মিনিট ৫: P5 — প্রাক-ক্রয় ডিউ ডিলিজেন্স (Due Diligence Risk Report)**
   - ডেমো বার থেকে পুনরায় **"১. নাগরিক"** নির্বাচন করে **"জমি কেনার আগে যাচাই (P5)"**-এ যান।
   - **"দৃশ্যকল্প ২: একাধিকবার বিক্রি ও মামলা"** ক্লিক করে বিশ্লেষণ চালান।
   - উচ্চ ঝুঁকি সতর্কতা (High Risk), স্বচ্ছ পয়েন্ট বন্টন, বালামের প্রমাণক সূত্র এবং ৫টি জরুরি করণীয় প্রদর্শন করুন।

## 🛠️ আর্কিটেকচার ও টেকনিক্যাল স্ট্যাক (Architecture)

### ফ্রন্টএন্ড (Frontend)
- **ফ্রেমওয়ার্ক:** React 18 + Vite 6
- **স্টাইলিং:** Tailwind CSS + Custom Government Portal Theme Tokens
- **আইকন:** Lucide React
- **কিউআর কোড:** Real client-side canvas generation using `qrcode`
- **ইন্টারন্যাশনালাইজেশন:** Custom reactive Context i18n (`bn` default, `en` secondary)
- **থিম:** Tailwind Dark Mode with `localStorage` persistence

### ব্যাকএন্ড (Backend)
- **ফ্রেমওয়ার্ক:** FastAPI 0.143 (Python 3.13)
- **ডেটাবেজ:** SQLite 3 (সম্পূর্ণ রিলেশনাল স্কিমা: Users, Properties, Deeds, Verifications, MutationApplications, StatusHistory, DueDiligenceReports, AuditLogs, Notifications)
- **পাসওয়ার্ড সিকিউরিটি:** PBKDF2-HMAC-SHA256 (১,০০,০০০ ইটারেশন ও সল্ট)
- **এআই ও অ্যানোমালি ইঞ্জিন:** Scikit-learn (Isolation Forest) + Transparent Rule-Based Conflict Engine
- **ডকুমেন্ট এক্সট্রাকশন:** `pypdf` ও রেগুলার এক্সপ্রেশন পার্সার

## 📄 বাস্তবায়িত ১৯টি প্রয়োজনীয় পেজ (Implemented 19 Views)

1. **Login (`/login`):** ব্যবহারকারী নাম/ইমেইল ও পাসওয়ার্ড, পাসওয়ার্ড টগল, ডেমো অ্যাকাউন্ট বোতাম।
2. **Citizen Registration (`/register`):** নাগরিক নিবন্ধন ফরম ও ফিল্ড ভ্যালিডেশন।
3. **Home / Landing Page (`/`):** সমস্যা বিবৃতি, ৩টি ফিচার কার্ড, কর্মপদ্ধতি, এআই বিশ্লেষণ ব্যাখ্যা ও এফএকিউ।
4. **Citizen Dashboard (`/dashboard`):** রিয়েল ডেটাবেজ মেট্রিক্স, দ্রুত অ্যাকশন বোতাম, চার্ট ও অ্যাক্টিভিটি।
5. **Deed Verification (`/verify-deed`):** দলিল ইনপুট ফরম, ড্র্যাগ অ্যান্ড ড্রপ ফাইল আপলোড, ডেমো প্রিসেট।
6. **Verification Result & Report (`/verify-deed/:ref`):** বালাম তুলনা টেবিল, কিউআর কোড, প্রিন্ট ভিউ।
7. **Smart E-Namjari Application (`/mutation/new`):** ৪-ধাপের উইজার্ড, খসড়া সংরক্ষণ ও দাখিল।
8. **Application Tracking (`/mutation/track`):** সার্চ, প্রগ্রেস বার, টাইমলাইন এবং কর্মকর্তাদের আদেশ।
9. **Officer Review Dashboard (`/officer/applications`):** কর্মকর্তাদের আবেদন পর্যালোচনা, অনুমোদন ও নোটিশ।
10. **Pre-Purchase Land Checking (`/due-diligence`):** প্রাক-ক্রয় স্ক্রীনিং ইনপুট ও ডেমো দৃশ্যকল্প।
11. **Risk Assessment Report (`/due-diligence/:ref`):** সার্বিক ঝুঁকি মাত্রা, স্কোর, প্রমাণক ও ৫টি করণীয়।
12. **Properties & Parcel Register (`/properties`):** প্লট তালিকা, ফিল্টার এবং দলিল ইতিহাস।
13. **Activity & Audit History (`/audit-logs`):** রিয়েলটাইম অডিট ট্রেইল ও অ্যাক্টিভিটি হিস্ট্রি।
14. **Notifications (`/notifications`):** ইন-অ্যাপ নোটিফিকেশন কেন্দ্র ও পঠিত চিহ্নিতকরণ।
15. **User Profile & Settings (`/profile`):** ব্যবহারকারীর এনআইডি, পদবি, ভাষা ও থিম সেটিংস।
16. **Administrator Dashboard (`/admin`):** সিস্টেম স্বাস্থ্য ও ১-ক্লিক ডেটাবেজ রিসেট/সিডিং।
17. **Help, FAQ & Methodology (`/help`):** স্কোরিং পদ্ধতি ব্যাখ্যা ও বাংলাদেশ ভূমি পরিভাষা।
18. **Privacy Policy & Disclaimer (`/disclaimer`):** সিন্থেটিক ডেটা ও আইনি সীমাবদ্ধতা ঘোষণা।
19. **Custom 404 & Error Page:** সরকারি পোর্টাল স্টাইলের ৪০৪ ত্রুটি পৃষ্ঠা।

> ২. সিস্টেমে তথ্যের মিল থাকা মানেই চূড়ান্ত আইনি মালিকানা প্রতিষ্ঠা নয়।
> ৩. এআই সূচকগুলো কেবল সম্ভাব্য গরমিল নির্দেশ করে; এটি কোনো আইনি মতামত বা প্রতারণার চূড়ান্ত রায় নয়।
> ৪. উৎপন্ন কিউআর কোড কেবল ল্যান্ডগার্ড এআই প্ল্যাটফর্মের অভ্যন্তরীণ বৈধতা প্রমাণ করে, এটি সরকারি নিরাপত্তা সিল নয়।
